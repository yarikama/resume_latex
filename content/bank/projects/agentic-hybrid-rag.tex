\resumeItem{\textbf{Agentic Query Routing:} Built a \textbf{LangGraph} state graph in which a CrewAI query-classification agent sends each question to no retrieval, to global search over Neo4j community summaries for broad questions, or to local entity-and-relationship search for specific ones, scoring each question's scope to choose}

% Notes:    the 0.7 / 0.3 weights belong to Milvus's dense+sparse ranker, not to Cohere.
\resumeItem{\textbf{Hybrid Retrieval:} Backed both graph paths with \textbf{Milvus} dense+sparse hybrid search (weighted 0.7/0.3, top 8), seeding the vector queries with the candidate answers the graph step produced, then reranked the passages with Cohere at a 0.2 relevance cutoff before generation}
% -------------------------------------------------------------------------------------
% FACET: Multi-hop retrieval quality                    angles: retrieval, evaluation
% Evidence: Henry-attested 2026-10-09 for 88.2% MAR@10 (source to be supplied);

\resumeItem{\textbf{Graph-Seeded Retrieval:} Fed graph-search results into vector retrieval with HyDE, generating hypothetical answers to search with when the graph finds nothing, and reached an MAR@10 of \textbf{88.2\%} on multi-hop questions}

\resumeItem{\textbf{Clustered Graph Indexing:} Clustered the vector store with K-means and DBSCAN and sampled each cluster's pivotal chunks as the graph-indexing input, saving \textbf{35\%} of indexing token cost for only 2.56\% worse RAGAS scores}
% -------------------------------------------------------------------------------------

\resumeItem{\textbf{Map-Reduce Global Search:} Ran global search as a LangGraph map-reduce, fanning community summaries out in batches of 5 with \textbf{Send}, drafting a summary and candidate answers per batch, then reranking and reducing them before the vector step}
% -------------------------------------------------------------------------------------
% FACET: Local graph search                              angles: retrieval, graph

\resumeItem{\textbf{Local Graph Search:} Wrote the Cypher retrieval for specific questions, matching relationships by vector similarity and entities by keyword, then falling back to community retrieval and then to HyDE when a question finds nothing}
